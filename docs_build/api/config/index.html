    API Reference — reaper.config¶

    ScraperConfig¶

    reaper.config.ScraperConfig dataclass ¶

    ScraperConfig(
    url: str,
    headless: bool = True,
    debug: bool = False,
    screenshot: bool = False,
    auto_scroll: bool = False,
    infinity_scroll: bool = False,
    proxy_server: str | None = None,
    proxy_username: str | None = None,
    proxy_password: str | None = None,
    artifacts_dir: Path = (
        lambda: Path("data/debug_artifacts")
    )(),
    results_dir: Path = (lambda: Path("data/results"))(),
    account_manager: Any = None,
    preferred_account: str | None = None,
)

    Configuración completa para una sesión de scraping.

    Es el único objeto de configuración que existe en la librería. Se crea en Reaper.scrape() y se pasa a todos los componentes sin modificación.

    Parameters:

    Name Type Description Default
    url str

    URL objetivo a scrapear. Único parámetro obligatorio. Debe empezar con http:// o https://.

    		 required
    headless bool

    Ejecutar Firefox sin interfaz gráfica. Recomendado True en producción. Defecto: True.

    		 True
    debug bool

    Activar logging DEBUG y guardar artefactos (HTML, screenshots, tráfico GraphQL) en artifacts_dir. Defecto: False.

    		 False
    screenshot bool

    Capturar PNG del contenedor principal al cargar la página. Útil para diagnóstico visual. Defecto: False.

    		 False
    auto_scroll bool

    Scroll automático midiendo cambios de scrollHeight del DOM. Recomendado para cargar comentarios paginados. Defecto: True.

    		 False
    infinity_scroll bool

    Scroll continuo monitorizando actividad de red. Para feeds con carga infinita (grupos, búsquedas). Requiere auto_scroll=True. Defecto: False.

    		 False
    proxy_server str | None

    URL del proxy, p.ej. "http://ip:8080" o "socks5://ip:1080". Defecto: None.

    		 None
    proxy_username str | None

    Usuario del proxy. Ignorado si no hay proxy_server. Defecto: None.

    		 None
    proxy_password str | None

    Contraseña del proxy. Igual que proxy_username. Defecto: None.

    		 None
    artifacts_dir Path

    Directorio para artefactos de debug (screenshots, HTML, tráfico). Solo se usa si debug=True. Defecto: data/debug_artifacts.

    		 (lambda: Path('data/debug_artifacts'))()
    results_dir Path

    Directorio para guardar resultados JSON. Defecto: data/results.

    		 (lambda: Path('data/results'))()

    Raises:

    Type Description
    ValueError

    Si alguna invariante de configuración se viola: - URL vacía. - Esquema de URL inválido (no http/https). - Credenciales de proxy sin servidor de proxy. - infinity_scroll=True con auto_scroll=False.

    has_proxy property ¶

    has_proxy: bool

    True si hay un servidor proxy configurado.

    proxy_config property ¶

    proxy_config: dict[str, str] | None

    Devuelve el dict de proxy listo para Playwright, o None.

    Playwright espera la estructura::

    {"server": "...", "username": "...", "password": "..."}

    Returns:

    Type Description
    dict[str, str] | None

    Dict con server (y opcionalmente username/password),
    dict[str, str] | None

    o None si no hay proxy configurado.

    has_account_manager property ¶

    has_account_manager: bool

    True si hay un AccountManager configurado para rotación de cuentas.
