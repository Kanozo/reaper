    scrape()¶

    reaper.scrape async ¶

    scrape(
    url: str,
    *,
    account_manager: AccountManager | None = None,
    headless: bool = True,
    debug: bool = False,
    screenshot: bool = False,
    auto_scroll: bool = True,
    infinity_scroll: bool = False,
    proxy_server: str | None = None,
    proxy_username: str | None = None,
    proxy_password: str | None = None,
    account: str | None = None,
) -> dict[str, Any]

    Scrape una URL y devuelve los datos extraídos como diccionario.

    Función de conveniencia a nivel de módulo. Internamente crea una instancia de Reaper y delega en Reaper.scrape().

    Para múltiples scrapes con rotación de cuentas, es más eficiente usar la clase Reaper directamente, ya que reutiliza el AccountManager entre peticiones sin recrearlo.

    Parameters:

    Name Type Description Default
    url str

    URL de Facebook o Instagram a scrapear. Obligatorio.

    		 required
    account_manager AccountManager | None

    Gestor de cuentas para rotación autenticada. None = modo anónimo (defecto).

    		 None
    headless bool

    Ejecutar Firefox sin interfaz gráfica. Defecto: True.

    		 True
    debug bool

    Logging detallado + artefactos. Defecto: False.

    		 False
    screenshot bool

    Capturar PNG del contenedor principal. Defecto: False.

    		 False
    auto_scroll bool

    Scroll automático por altura DOM. Defecto: True.

    		 True
    infinity_scroll bool

    Scroll continuo por tráfico de red. Defecto: False.

    		 False
    proxy_server str | None

    URL del proxy, p.ej. "http://ip:8080".

    		 None
    proxy_username str | None

    Usuario del proxy.

    		 None
    proxy_password str | None

    Contraseña del proxy.

    		 None
    account str | None

    Cuenta a forzar en esta sesión (account_id, username o ID de usuario de la plataforma). Requiere account_manager. None = rotación automática.

    		 None

    Returns:

    Type Description
    dict[str, Any]

    dict[str, Any] con los datos scrapeados.
    dict[str, Any]

    Siempre incluye: url, platform, status.

    Raises:

    Type Description
    ValueError

    URL vacía o esquema inválido.
    UnsupportedPlatformError

    URL no es Facebook ni Instagram.
    ScrapingError

    Error en runtime durante fetch o parseo.

    Examples::

    # Modo anónimo (comportamiento original)
result = asyncio.run(scrape("https://www.instagram.com/p/abc123"))

# Con cuenta autenticada
manager = AccountManager()
await manager.add_account("facebook", "usuario", cookies=[...])
result = await scrape(
    "https://www.facebook.com/reel/123",
    account_manager=manager,
)

# Forzar una cuenta concreta por username
result = await scrape(
    "https://www.facebook.com/reel/123",
    account_manager=manager,
    account="mi_usuario@gmail.com",
)

    Reaper¶

    reaper.core.Reaper ¶

    Reaper(account_manager: 'AccountManager | None' = None)

    Orquestador principal de Reaper.

    Puede reutilizarse para múltiples scrapes manteniendo el mismo AccountManager, lo que permite que el rotador acumule historial de actividad entre peticiones.

    Parameters:

    Name Type Description Default
    account_manager 'AccountManager | None'

    Gestor de cuentas para rotación autenticada. None = modo anónimo (comportamiento original).

    		 None

    Ejemplo con cuentas::

    from reaper.auth import AccountManager
from reaper import Reaper

manager = AccountManager()
reaper  = Reaper(account_manager=manager)

result = await reaper.scrape("https://www.facebook.com/reel/123")
result = await reaper.scrape("https://www.instagram.com/p/abc/")

    Ejemplo sin cuentas (comportamiento original)::

    reaper = Reaper()
result = await reaper.scrape("https://www.facebook.com/reel/123")

    reaper.actions.ActionResult dataclass ¶

    ActionResult(
    action: str,
    platform: str = "facebook",
    action_id: str = (lambda: uuid.uuid4().hex)(),
    account_id: str | None = None,
    account_username: str | None = None,
    status: str = "ok",
    post_url: str | None = None,
    post_id: str | None = None,
    comment_id: str | None = None,
    group: str | None = None,
    text: str | None = None,
    error: str | None = None,
    executed_at: str = _now_iso(),
)

    Registro del resultado de una acción de escritura ejecutada.

    Es el contrato de datos entre ActionManager, el SessionActor y el almacenamiento de acciones. Se serializa con to_dict() / from_dict() para persistir en cualquier backend (JSON, PostgreSQL, MongoDB).

    Attributes:

    Name Type Description
    action_id str

    UUID4 interno del registro. Se genera al ejecutar.
    action str

    Valor de ActionType ("post", "comment", ...).
    platform str

    Plataforma sobre la que se ejecutó ("facebook").
    account_id str | None

    UUID4 de la cuenta autenticada usada.
    account_username str | None

    Username de la cuenta (para logs/auditoría).
    status str

    "ok" si la plataforma confirmó la acción, "error" si falló.
    post_url str | None

    URL de la publicación creada o objetivo.
    post_id str | None

    ID de la publicación creada o objetivo (si se detecta).
    comment_id str | None

    ID del comentario publicado (solo comment).
    group str | None

    Identificador del grupo (id o URL) para acciones de grupo.
    text str | None

    Texto enviado (contenido del post o del comentario).
    error str | None

    Mensaje de error cuando status="error".
    executed_at str

    Timestamp UTC ISO-8601 de la ejecución.

    reaper.actions.ActionType ¶

    Bases: str, Enum

    Tipo de acción de escritura soportada por Reaper.

    Valores

    POST: Crear una publicación nueva en el muro de la cuenta. GROUP_POST: Publicar un post nuevo directamente dentro de un grupo. SHARE_TO_GROUP: Compartir una publicación existente dentro de un grupo. COMMENT: Responder con texto a una publicación existente. LIKE: Reaccionar con "Me gusta" a una publicación existente.

    reaper.actions.ActionError ¶

    Bases: Exception

    Error en la ejecución de una acción de escritura.

    Se lanza cuando la acción no puede ejecutarse: falta de cuenta con cookies válidas, elemento de la interfaz no encontrado, o la plataforma rechaza la operación.
