    BaseParser¶

    reaper.parsers.base_parser.BaseParser ¶

    BaseParser(
    html_content: str,
    final_url: str,
    original_url: str = "",
    traffic: CapturedTraffic | None = None,
    debug: bool = False,
    platform: str = "",
)

    Bases: ABC

    Clase base abstracta para todos los parsers de contenido.

    Define la interfaz común y utilidades plataforma-agnósticas. No instanciar directamente; usar siempre una subclase concreta.

    Attributes:

    Name Type Description
    html_content

    HTML crudo de la página a parsear.
    final_url

    URL final (tras redirecciones) de la página capturada.
    original_url

    URL original solicitada por el usuario.
    traffic

    Tráfico de red capturado con GraphQL responses.
    debug

    Si True, emite logs de diagnóstico adicionales vía logging.
    result dict[str, Any]

    Esqueleto de resultado garantizado. Siempre contiene: platform, status, error, raw_data_available, scraped_at, final_url, post_url. Las subclases extienden este dict con sus campos específicos vía self.result.update({...}) en su propio __init__.

    Inicializa el parser base y construye el esqueleto de resultado.

    Parameters:

    Name Type Description Default
    html_content str

    HTML completo renderizado de la página.

    		 required
    final_url str

    URL final de la página (puede diferir de la original).

    		 required
    original_url str

    URL original solicitada por el usuario. Si está vacía se usa final_url como fallback.

    		 ''
    traffic CapturedTraffic | None

    Tráfico de red capturado durante el fetch. CRUCIAL: Los parsers deben usar esto para obtener datos estructurados de las APIs GraphQL.

    		 None
    debug bool

    Si True, activa logs de diagnóstico en nivel DEBUG.

    		 False
    platform str

    Identificador de plataforma ("facebook" o "instagram"). Poblado por las subclases concretas.

    		 ''

    Raises:

    Type Description
    ValueError

    Si html_content está vacío.

    _extract_json_blocks ¶

    _extract_json_blocks() -> list[dict]

    Extrae y parsea todos los bloques JSON embebidos en el HTML.

    Busca etiquetas <script type="application/json"> y parsea su contenido. Los bloques inválidos se descartan silenciosamente (o con log DEBUG si self.debug está activo).

    Returns:

    Type Description
    list[dict]

    Lista de dicts, uno por cada bloque JSON válido encontrado.
    list[dict]

    Retorna lista vacía si no hay bloques o si el HTML es inválido.

    _recursive_search ¶

    _recursive_search(
    data: Any,
    condition: Callable[[dict], bool],
    extract: Callable[[dict], Any] | None = None,
) -> Any | None

    Búsqueda Depth-First en una estructura de datos anidada.

    Recorre dicts y listas recursivamente hasta encontrar el primer nodo que cumpla condition.

    Parameters:

    Name Type Description Default
    data Any

    Raíz de la estructura a explorar.

    		 required
    condition Callable[[dict], bool]

    Callable que recibe un dict y retorna True si es el nodo buscado.

    		 required
    extract Callable[[dict], Any] | None

    Callable opcional para transformar el nodo encontrado antes de retornarlo.

    		 None

    Returns:

    Type Description
    Any | None

    El primer nodo encontrado (o su transformación si se
    Any | None

    proporcionó extract), o None si no se encontró.
    Example

    node = self._recursive_search( ... block, ... condition=lambda n: n.get("__isFeedUnit") == "Story", ... )

    _find_all_nodes ¶

    _find_all_nodes(
    data: Any,
    condition: Callable[[dict], bool],
    depth: int = 0,
    max_depth: int = 50,
) -> list[dict]

    Búsqueda DFS que recopila TODOS los nodos que cumplen la condición.

    A diferencia de _recursive_search, no se detiene en el primer resultado sino que acumula todos los nodos coincidentes.

    Parameters:

    Name Type Description Default
    data Any

    Estructura de datos a recorrer.

    		 required
    condition Callable[[dict], bool]

    Función que retorna True si el nodo cumple el criterio.

    		 required
    depth int

    Profundidad actual (uso interno para la recursión).

    		 0
    max_depth int

    Profundidad máxima de recursión para evitar stack overflow.

    		 50

    Returns:

    Type Description
    list[dict]

    Lista con todos los nodos que cumplen la condición.
    Example

    stories = self._find_all_nodes( ... block, ... condition=lambda n: n.get("__typename") == "Story", ... )

    data: Any, *keys: str, default: Any = None

    Evita KeyError y TypeError al acceder a estructuras JSON profundamente anidadas cuya existencia no está garantizada.

    Parameters:

    Name Type Description Default
    data Any

    Diccionario raíz desde el que iniciar la navegación.

    		 required
    *keys str

    Secuencia de claves que forman la ruta de navegación.

    		 ()
    default Any

    Valor a retornar si la ruta no existe o es None.

    		 None

    Returns:

    Type Description
    Any

    El valor al final de la ruta, o default si algún paso
    Any

    falla o retorna None.
    Example

    url = self._safe_get(actor, "profile_picture", "uri", default="") count = self._safe_get(feedback, "reaction_count", "count", default=0)
