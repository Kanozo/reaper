    API Reference — reaper.network¶

    ContentFetcher¶

    reaper.network.content_fetcher.ContentFetcher ¶

    ContentFetcher(
    url: str,
    headless: bool = True,
    debug: bool = False,
    config: BrowserConfig | None = None,
)

    Obtiene HTML completamente renderizado de una URL con Playwright (Firefox).

    Orquesta la navegación, la interceptación de red y las técnicas de scroll. Actúa como facade sobre Playwright: el código consumidor solo interactúa con fetch() y recibe un FetchResult completamente tipado.

    Responsabilidad única

    Navegar a una URL, activar la captura de tráfico de red, esperar la carga completa del contenido dinámico y devolver HTML + tráfico. NO parsea, NO interpreta, NO extrae datos de la página.

    Modos de scroll
    • auto_scroll=True: scroll midiendo cambios de scrollHeight DOM. Recomendado para posts individuales con comentarios.
    • infinity_scroll=True: scroll monitorizando actividad de red. Recomendado para feeds y búsquedas largas.
    • Ambos False: sin scroll (posts simples, Instagram).

    Uso básico::

    fetcher = ContentFetcher("https://www.facebook.com/reel/XXXXXX")
result = await fetcher.fetch(auto_scroll=True)
if result.success:
    html = result.html_content
    traffic = result.traffic

    Parameters:

    Name Type Description Default
    url str

    URL completa de la página a obtener.

    		 required
    headless bool

    Si True, lanza el navegador sin interfaz gráfica. Recomendado True en producción y daemons.

    		 True
    debug bool

    Si True, activa logs detallados, guarda screenshots, HTML y tráfico de red en BrowserConfig.DEBUG_OUTPUT_DIR.

    		 False
    config BrowserConfig | None

    Instancia de BrowserConfig con parámetros personalizados. Si None, usa la configuración por defecto.

    		 None

    Raises:

    Type Description
    ValueError

    Si url está vacía o no es un string.

    fetch async ¶

    fetch(
    screenshot: bool = False,
    auto_scroll: bool = False,
    infinity_scroll: bool = False,
    proxy_server: str | None = None,
    proxy_username: str | None = None,
    proxy_password: str | None = None,
    cookies: list[dict] | None = None,
) -> FetchResult

    Ejecuta la navegación completa y retorna HTML + tráfico de red.

    Flujo interno
    1. Crear NetworkInterceptor y FetchResult base.
    2. Lanzar Firefox con configuración anti-detección.
    3. Crear contexto (viewport, user-agent, locale, proxy opcional).
    4. Adjuntar el interceptor ANTES de navegar (captura desde inicio).
    5. Navegar a la URL y esperar networkidle.
    6. (Opcional) Capturar screenshot del contenedor principal.
    7. (Opcional) Ejecutar scroll (auto o infinity).
    8. Capturar el HTML final (page.content()).
    9. (Debug) Guardar artefactos en disco.
    10. Cerrar navegador y retornar FetchResult.

    Parameters:

    Name Type Description Default
    screenshot bool

    Captura PNG del contenedor div[role='dialog'].

    		 False
    auto_scroll bool

    Scroll midiendo cambios de altura DOM.

    		 False
    infinity_scroll bool

    Scroll monitorizando tráfico de red. Tiene prioridad sobre auto_scroll si ambos True.

    		 False
    proxy_server str | None

    URL del proxy (ej: "http://ip:port").

    		 None
    proxy_username str | None

    Usuario para autenticación del proxy.

    		 None
    proxy_password str | None

    Contraseña para autenticación del proxy.

    		 None
    cookies list[dict] | None

    Lista de cookies en formato Playwright a inyectar en el contexto del navegador antes de navegar. Permite sesiones autenticadas sin login interactivo. None = navegación anónima.

    		 None

    Returns:

    Type Description
    FetchResult

    FetchResult con HTML renderizado, tráfico capturado y metadatos.
    FetchResult

    Si falla, success=False y error describe el problema.

    BrowserConfig¶

    reaper.network.content_fetcher.BrowserConfig ¶

    BrowserConfig()

    Parámetros de configuración del navegador y comportamiento de scroll.

    Centraliza los ajustes en un único lugar sin tocar la lógica de navegación. Para personalizar, instancia y sobreescribe atributos de instancia::

    cfg = BrowserConfig()
cfg.PAGE_LOAD_WAIT = 8.0
cfg.MAX_SCROLL_ITERATIONS = 30
fetcher = ContentFetcher(url, config=cfg)

    FetchResult¶

    reaper.network.interceptor.FetchResult dataclass ¶

    FetchResult(
    original_url: str,
    final_url: str | None = None,
    html_content: str | None = None,
    traffic: CapturedTraffic | None = None,
    fetched_at: datetime = datetime.now(),
    success: bool = False,
    error: str | None = None,
    authenticated: bool = False,
    account_id: str | None = None,
    debug_session_dir: Path | None = None,
)

    Resultado completo de una operación de obtención de contenido.

    Encapsula el HTML renderizado, el tráfico de red y los metadatos de sesión. En caso de error, success=False y error describe el fallo.

    Attributes:

    Name Type Description
    original_url str

    URL solicitada originalmente.
    final_url str | None

    URL final tras redirecciones.
    html_content str | None

    HTML renderizado (DOM final con JS ejecutado), o None.
    traffic CapturedTraffic | None

    Tráfico de red capturado (GraphQL + API).
    fetched_at datetime

    Timestamp de la captura.
    success bool

    True si el HTML fue obtenido sin errores críticos.
    error str | None

    Mensaje descriptivo si success=False.
    authenticated bool

    True si la sesión usó cookies de autenticación.
    account_id str | None

    ID de la cuenta usada para la sesión autenticada.
    debug_session_dir Path | None

    Path al directorio de debug. None si debug=False.
    Notes

    Los parsers deben usar traffic.graphql_responses para datos estructurados en lugar de depender únicamente del HTML.

    CapturedTraffic¶

    reaper.network.interceptor.CapturedTraffic dataclass ¶

    CapturedTraffic(
    graphql_requests: list[CapturedRequest] = list(),
    graphql_responses: list[CapturedResponse] = list(),
    api_requests: list[CapturedRequest] = list(),
    api_responses: list[CapturedResponse] = list(),
)

    Tráfico de red completo capturado durante una sesión de fetch.

    Organiza requests y responses por categoría para acceso directo desde los parsers. Exclusivo para Facebook (graphql) e Instagram (api).

    Uso desde parsers::

    for resp in result.traffic.graphql_responses:
    if resp.body:
        data = resp.body.get("data", {})

search_responses = result.traffic.graphql_by_operation("SearchResultsPage")

    Attributes:

    Name Type Description
    graphql_requests list[CapturedRequest]

    Peticiones a /api/graphql/.
    graphql_responses list[CapturedResponse]

    Respuestas de las operaciones GraphQL.
    api_requests list[CapturedRequest]

    Peticiones a /api/v1/ (Instagram REST API).
    api_responses list[CapturedResponse]

    Respuestas de la API REST de Instagram.
